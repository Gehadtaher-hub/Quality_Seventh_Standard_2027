# بوابة المعيار السابع

تتضمن النسخة الحالية:
- توصيف مقررات علوم الحاسب.
- توصيف مقررات نظم المعلومات.
- ملاحظات مراجعي مقررات علوم الحاسب.
- ملاحظات مراجعي مقررات نظم المعلومات.
- نتائج واستبيانات المقررات.
- مكانين محجوزين لتقارير برنامجي علوم الحاسب ونظم المعلومات.

## إضافة روابط تقارير البرامج
افتح `assets/data.js`، ثم استبدل `#` في روابط التقارير بالرابط المطلوب، واستبدل `pending` بـ `ready`، وغيّر `قيد الإضافة` إلى `Google Drive`.

## النشر
ارفع محتويات الحزمة إلى مستودع GitHub، ثم من `Settings > Pages` اختر `Deploy from a branch` ثم `main` و`/ (root)`.
