# بوابة المعيار السابع
الموقع منظم إلى: **التوصيفات، التقارير، المراجعات**.

## إضافة الروابط
افتح `assets/data.js` واستبدل كل `#` برابط Google Drive المقابل. اجعل صلاحية الرابط `Anyone with the link` إذا كان الموقع عامًا.

## النشر
ارفع محتويات الحزمة إلى مستودع GitHub، ثم افتح `Settings > Pages` واختر `Deploy from a branch` ثم `main` و`/ (root)`.
